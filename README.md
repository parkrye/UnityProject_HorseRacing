# Horse Racing

경마 시뮬레이션 (Unity · URP, 2023). 레이스 전에 말 한 마리에 배팅하고, AI 말들이 각자의 능력치와 각질로 달리는 레이스를 지켜본다.

## 말

- 능력치: 속도 · 스태미나 · 파워 · 지능 (말마다 기본값에서 ±10% 무작위)
- 각질 4종 — 레이스 중 순위에 따라 속도를 조절하다가 스퍼트 구간에서 전력 질주
  - **도주** (Runway): 1위를 지키려 한다
  - **선행** (Front): 도주마 바로 뒤에 붙는다
  - **선입** (Stalker): 선행 그룹 뒤에서 기회를 본다
  - **추입** (Closer): 후방에서 버티다 막판에 치고 나온다
- 스태미나가 바닥나면 속도가 절반으로 떨어진다

## 레이스

- 코스: 마일 · 장거리
- 배당률은 말의 능력치 합에 반비례 — 약한 말일수록 배당이 높다
- 배팅 금액 · 경기 수 기록, 적중 시 배당 지급
- 순위 실시간 표시, 레이스 카메라
